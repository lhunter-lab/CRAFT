This set of CRAFT TAXRANK concept annotations was created with the TAXRANK ontology of taxonomic ranks, which is provided in this GitHub folder and which we recommend using so as to maximize consistency with these concept annotations.  In previous versions of the CRAFT Corpus, classes representing these taxonomic ranks within the NCBI Taxonomy (NCBITaxon) ontology were used for these concepts; however, these concepts have now been deprecated within the NCBITaxon ontology and the new TAXRANK ontology has instead been developed.

These annotations are provided in two sets, within the TAXRANK and TAXRANK_integrated+extended subfolders.  The former exclusively uses proper TAXRANK classes for concept annotation, while the latter additionally uses what we call TAXRANK extension classes, which are classes we have created for CRAFT TAXRANK concept annotation but for which we have specified relationships to proper TAXRANK classes.  These are several (not mutually exclusive) rationales for the creation of these extension classes, including (1) semantic integration of semantically equivalent or (textually) indistinguishable classes among two or more of the ontologies used for CRAFT concept annotation; (2) semantic abstraction of one or more TAXRANK classes and possibly one or more classes of other ontologies used for CRAFT concept annotation; and (3) annotation of closely related concepts that entail the existence or absence of existence of proper TAXRANK classes.  These extension classes are provided within the TAXRANK_integrations+extensions.owl ontology file, in which each extension class has been related to one or more proper TAXRANK classes with an annotation properties subsumed by the superproperty has_related_TAXRANK_class.  Note that the TAXRANK_integrated+extended annotation set is *not* monotonic relative to the TAXRANK annotation set, as some of the annotations made with proper TAXRANK classes in the latter are replaced with annotations made with corresponding TAXRANK extension classes in the former.

Additionally, most of the TAXRANK concept annotations have what we refer to as an interpretation, specifically in the form of textual attribute values within their XML annotation elements.  These interpretations indicate that the classes used for the annotations should be semantically interpreted as referring to a biological taxonomic rank (e.g., the taxonomic rank of strain) or to the kind(s) of organism(s) that constitute(s) the taxonomic rank (e.g., instances of organisms constituting the given mentioned strain).  These have been created so as to account for the complexity of several possible related semantic interpretations of these TAXRANK classes as used in concept annotations, but implemented so as not to create and maintain parallel hierarchies of new extension classes mirroring proper TAXRANK classes.
