This updated set of CRAFT CHEBI concept annotations was created with a newer version of the CHEBI ontology, which is provided in this GitHub folder and which we recommend using so as to maximize consistency with these concept annotations.

These annotations are provided in two sets, within the CHEBI and CHEBI_integrated+extended subfolders.  The former exclusively uses proper CHEBI classes for concept annotation, while the latter additionally uses what we call CHEBI extension classes, which are classes we have created for CRAFT CHEBI concept annotation but for which we have specified relationships to proper CHEBI classes.  These are several (not mutually exclusive) rationales for the creation of these extension classes, including (1) semantic integration of semantically equivalent or (textually) indistinguishable classes among two or more of the ontologies used for CRAFT concept annotation; (2) semantic abstraction of one or more CHEBI classes and possibly one or more classes of other ontologies used for CRAFT concept annotation; and (3) annotation of closely related concepts that entail the existence or absence of existence of proper CHEBI classes.  These extension classes are provided within the CHEBI_integrations+extensions.owl ontology file, in which each extension class has been related to one or more proper CHEBI classes with an annotation properties subsumed by the superproperty has_related_CHEBI_class.  Note that the CHEBI_integrated+extended annotation set is *not* monotonic relative to the CHEBI annotation set, as some of the annotations made with proper CHEBI classes in the latter are replaced with annotations made with corresponding CHEBI extension classes in the former.

Additionally, some of the CHEBI concept annotations have what we refer to as interpretations, specifically in the form of textual attribute values within their XML annotation elements.  These interpretations indicate that the classes used for the annotations should be semantically interpreted in specific ways, explained in the 'CHEBI interpretations.txt' file.  These have been created so as to account for the complexity of several possible related semantic interpretations of these CHEBI classes as used in concept annotations, including the conceptualizations of the classes as their formal definitions and/or as closely related concepts, but implemented so as not to create and maintain large, complex parallel hierarchies of new extension classes mirroring proper CHEBI classes.
