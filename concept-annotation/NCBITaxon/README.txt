This updated set of CRAFT NCBITaxon concept annotations was created with a newer version of the NCBITaxon ontology, which is provided in this GitHub folder and which we recommend using so as to maximize consistency with these concept annotations.

These annotations are provided in two sets, within the NCBITaxon and NCBITaxon_integrated+extended subfolders.  The former exclusively uses proper NCBITaxon classes for concept annotation, while the latter additionally uses what we call NCBITaxon extension classes, which are classes we have created for CRAFT NCBITaxon concept annotation but for which we have specified relationships to proper NCBITaxon classes.  These are several (not mutually exclusive) rationales for the creation of these extension classes, including (1) semantic integration of semantically equivalent or (textually) indistinguishable classes among two or more of the ontologies used for CRAFT concept annotation; (2) semantic abstraction of one or more NCBITaxon classes and possibly one or more classes of other ontologies used for CRAFT concept annotation; and (3) annotation of closely related concepts that entail the existence or absence of existence of proper NCBITaxon classes.  These extension classes are provided within the NCBITaxon_integrations+extensions.owl ontology file, in which each extension class has been related to one or more proper NCBITaxon classes with an annotation properties subsumed by the superproperty has_related_NCBITaxon_class.  Note that the NCBITaxon_integrated+extended annotation set is *not* monotonic relative to the NCBITaxon annotation set, as some of the annotations made with proper NCBITaxon classes in the latter are replaced with annotations made with corresponding NCBITaxon extension classes in the former.

Additionally, most of the NCBITaxon concept annotations have what we refer to as an interpretation, specifically in the form of textual attribute values within their XML annotation elements.  These interpretations indicate that the classes used for the annotations should be semantically interpreted as referring to a biological taxon (e.g., the class Mammalia) or to the kind of organism that constitutes the taxon (e.g., mammal).  These have been created so as to account for the complexity of several possible related semantic interpretations of these NCBITaxon classes as used in concept annotations, but implemented so as not to create and maintain large, complex parallel hierarchies of new extension classes mirroring proper NCBITaxon classes.
