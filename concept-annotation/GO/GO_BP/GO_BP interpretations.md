**OCCURRENCE OR ATTRIBUTE**: Indicates that the annotation class can be interpreted as referring to either occurrences (e.g., the occurrence of gene expression) or as attributes of participant roles in these occurrences (e.g., the attribute of having been expressed (which would be one interpretation of this class mention in the phrase "this expressed gene") or the attribute of expressing something (e.g., which would be one interpretation of this class mention in the phrase "EYFP-expressing transgenic ES cells")).
