This updated set of CRAFT GO_CC concept annotations was created with a newer version of the GO_CC subontology, which is provided within the full Gene Ontology file in this GitHub folder and which we recommend using so as to maximize consistency with these concept annotations.

These annotations are provided in two sets, within the GO_CC and GO_CC_integrated+extended subfolders.  The former exclusively uses proper GO_CC classes for concept annotation, while the latter additionally uses what we call GO_CC extension classes, which are classes we have created for CRAFT GO_CC concept annotation but for which we have specified relationships to proper GO_CC classes.  These are several (not mutually exclusive) rationales for the creation of these extension classes, including (1) semantic integration of semantically equivalent or (textually) indistinguishable classes among two or more of the ontologies used for CRAFT concept annotation; (2) semantic abstraction of one or more GO_CC classes and possibly one or more classes of other ontologies used for CRAFT concept annotation; and (3) annotation of closely related concepts that entail the existence or absence of existence of proper GO_CC classes.  These extension classes are provided within the GO_CC_integrations+extensions.owl ontology file, in which each extension class has been related to one or more proper GO_CC classes with annotation properties subsumed by the superproperty has_related_GO_CC_class.  Note that the GO_CC_integrated+extended annotation set is *not* monotonic relative to the GO_CC annotation set, as some of the annotations made with proper GO_CC classes in the latter are replaced with annotations made with corresponding GO_CC extension classes in the former.
