This updated set of CRAFT CL concept annotations was created with a newer version of the CL ontology, which is provided in this GitHub folder and which we recommend using so as to maximize consistency with these concept annotations.

These annotations are provided in two sets, within the CL and CL_integrated+extended subfolders.  The former exclusively uses proper CL classes for concept annotation, while the latter additionally uses what we call CL extension classes, which are classes we have created for CRAFT CL concept annotation but for which we have specified relationships to proper CL classes.  These are several (not mutually exclusive) rationales for the creation of these extension classes, including (1) semantic integration of semantically equivalent or (textually) indistinguishable classes among two or more of the ontologies used for CRAFT concept annotation; (2) semantic abstraction of one or more CL classes and possibly one or more classes of other ontologies used for CRAFT concept annotation; and (3) annotation of closely related concepts that entail the existence or absence of existence of proper CL classes.  These extension classes are provided within the CL_integrations+extensions.owl ontology file, in which each extension class has been related to one or more proper CL classes with annotation properties subsumed by the superproperty has_related_CL_class.  Note that the CL_integrated+extended annotation set is *not* monotonic relative to the CL annotation set, as some of the annotations made with proper CL classes in the latter are replaced with annotations made with corresponding CL extension classes in the former.
